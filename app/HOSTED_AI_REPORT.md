# Laporan protected hosted AI — 4 Oktober 2026

Kode disiapkan untuk demo live AI di Vercel. Pengguna sudah mengisi environment provider tetapi **belum menghubungkan Redis**. Domain, model, kredensial, dan deployment pengguna tidak diperiksa. Tidak ada commit, push, deployment, provisioning akun, atau panggilan provider nyata.

## Sebelum dan sesudah

Sebelumnya server selalu memblokir live pada platform hosted; limiter dalam memori hanya sesuai demo lokal satu proses. Sekarang `AI_LIVE_MODE=public` dapat membuka akses jika passcode, signing secret, batas pemakaian, origin HTTPS eksplisit, dan Redis REST dengan kemampuan menulis/Lua lengkap. Default tetap disabled. Mode local tetap ditolak pada platform hosted.

Redis melakukan reservasi atomic untuk batas per menit, per hari UTC, dan concurrency lintas instance. Login dibatasi lima percobaan per 60 detik; logout menyimpan revocation. Namespace stabil mempertahankan quota setelah pergantian instance/deployment. Lease 60 detik memulihkan slot instance yang crash; percobaan provider yang gagal tidak mengembalikan budget. Ini batas jumlah panggilan, bukan batas tagihan dolar.

Cookie tetap signed, HttpOnly, Secure di HTTPS, SameSite=Strict, dengan masa berlaku 30 menit. Origin mutasi harus persis cocok; wildcard dan forwarded-host tidak membuka akses. Status memeriksa kemampuan Lua/menulis tanpa memanggil AI. Gangguan Redis gagal tertutup dengan pesan tersanitasi. Tidak ada token/kunci/endpoint Redis dalam respons produk.

Sesi yang tidak valid kembali ke form demo passcode; gangguan storage menyediakan retry status dan replay. Asset, mode, cutoff, tindakan lokal, dan data sumber tetap terpelihara. Provider tetap memakai ordinary chat completions, batas waktu 15 detik, tanpa retry/redirect otomatis, serta validasi schema, angka, evidence, dan eligibility yang sudah ada. Analyze menyediakan durasi 30 detik untuk round trip guard. Tidak ada perubahan CSS, aset, layout, dataset, formula, lockfile atau `.env.local`.

## Belum terverifikasi dan langkah pengguna

**NOT TESTED:** Vercel ingress/cold starts/deployment limits, Upstash akun pengguna, endpoint/model SumoPod nyata, provider billing, browser selain Chromium, perangkat fisik dan formal screen-reader review. Konfigurasi bukan bukti provider sukses. Health check memastikan command yang diperlukan dapat dipakai; tidak menggantikan verifikasi di platform nyata.

Hubungkan Redis REST dengan write-capable token; isi Production environment sesuai [panduan Vercel](README.md#protected-live-ai-on-vercel), terutama `AI_LIVE_MODE=public`, `AI_ALLOWED_ORIGINS` domain HTTPS persis, Redis URL/token, passcode, signing secret dan caps. Pertahankan provider key/model yang sudah diisi. Review lalu deploy kode/config terbaru secara terpisah. Buka Investigation → Demo passcode → Unlock live access → Request live AI composition. Periksa label hasil request; jika gagal, replay tetap tersedia. Kode tidak membuat live otomatis aktif hanya karena API key terpasang.
